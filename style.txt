PROMPT — Upgrade the Existing SOC Dashboard UI

I want you to improve the existing dashboard's frontend so it feels modern, dynamic, polished, and like a professional SOC/XDR command center.

IMPORTANT:
- Do NOT rewrite the entire application.
- Do NOT migrate to React unless there is a strong technical reason after inspecting the project.
- Preserve all existing backend functionality, routes, data models, authentication, APIs, and business logic.
- First inspect the existing project and understand how the dashboard currently works.
- Make incremental, well-structured changes.
- Do not remove existing functionality just to improve the UI.
- Keep the existing FastAPI + Jinja2 architecture unless there is a compelling reason to change it.

CURRENT STACK

The dashboard is currently developed with:

- Backend: FastAPI (Python)
- Templates: Jinja2
- Frontend: HTML5
- Styling/layout: Bootstrap 5.3 via CDN
- Charts: Chart.js 4 via CDN
- Interactivity: plain JavaScript + HTML forms
- Current UI routes include things such as revoke, approvals, policies, and IOC watchlist actions.

The current dashboard looks good stylistically, but it feels too static.

CURRENT PROBLEM

The dashboard currently behaves largely like a traditional server-rendered admin panel:

User action
    ↓
POST request
    ↓
Server processes request
    ↓
Entire page reloads

The visual design is already good, but I want it to feel much more alive and interactive.

GOAL

Transform the existing dashboard into a modern SOC/XDR-style dashboard with:

- Smooth animations
- Micro-interactions
- Animated statistics
- Dynamic charts
- Real-time or near-real-time updates
- Interactive tables
- AJAX/fetch-based actions
- Toast notifications
- Better loading states
- Live activity feeds
- Responsive interactions
- Subtle security/SOC visual effects

The dashboard should feel professional and sophisticated, NOT gimmicky.
